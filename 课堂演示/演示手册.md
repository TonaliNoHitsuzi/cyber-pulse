# 课堂演示手册 · 赛博把脉 CYBER-PULSE

> 目标场景：课堂投影展示 **实时脉搏波形 + 心率大字 + 手机摄像头特写** 同屏。
> 三件套：`serial_bridge.py`（串口桥）+ `index.html`（演示页）+ 手机（摄像头）。
> **讲台陌生机器友好**：所有接口（串口号/手机序列号/软件路径）启动时自动扫描，零硬编码。

---

## 0. 讲台部署（U 盘方案，3 分钟）

1. **整个 `课堂演示/` 文件夹拷 U 盘**（约 55MB，含绿色版 scrcpy+adb 和内置 Python 运行时，讲台机零安装）
2. 讲台机插上：板子 USB、手机 USB
3. 双击 **`启动演示.bat`** —— 自动体检环境 → 起串口桥 → 连手机开后摄 → 打开演示页

一键脚本等价命令：`python launch_demo.py`（`--no-cam` 只要波形；`--no-browser` 不自动开浏览器）。

**本机无需装 Python**：`runtime/python/` 已内置 3.12 + pyserial/websockets，`启动演示.bat` 自动优先使用；
汇报讲稿 #116 页的「启动现场演示」按钮也会调这个运行时（经 `serve.js` 的 `/demo/launch`）。

体检/排障单独跑：`python env_check.py`（只诊断不启动，逐项给修复建议）。

**手机侧一次性准备**（自己的手机提前做完再来）：
1. 设置 → 我的设备 → 全部参数 → 连点版本号 7 次，出现开发者选项
2. 开发者选项 → 开「USB 调试」
3. 插电脑后手机弹「允许 USB 调试」→ 允许（勾选一律允许）

**无 Python 的讲台机兜底**（bat 会自动提示）：双击 `index.html` → 页面点「接入 Web Serial」选 USB 串行设备 → 下拉框「窗口采集(scrcpy)」选 CYBER-CAM（先手动开 `bin\scrcpy\scrcpy.exe --video-source=camera --camera-facing=back -m1280 --no-audio --window-title CYBER-CAM`）。

## 1. 手动分步启动（调试/理解用）

### 第 1 步 · 串口桥（必须先跑）

```powershell
cd "D:\FileCenter\10-学期\大三上\单片机课程作业\课堂演示"
python serial_bridge.py
```

- 自动枚举 USB 串口（认 303A:1001，无需关心 COM 几），DTR/RTS 正确姿势打开（不复位板子）
- 同时起两个服务：`http://127.0.0.1:8100`（网页）+ `ws://127.0.0.1:8765`（数据）
- 设备静默 >8 秒会自动发 `rec wake` 自恢复；拔插串口自动重连
- 窗口保持开着（最小化不影响），Ctrl+C 退出

### 第 2 步 · 手机摄像头（scrcpy 路线，开发者模式+ADB，手机零安装）

手机前提见第 0 节。电脑启动相机窗口（绿色版在本目录）：

```powershell
& "课堂演示\bin\scrcpy\scrcpy.exe" --video-source=camera --camera-facing=back -m1280 --no-audio --stay-awake --window-borderless --window-title CYBER-CAM
```

> `--window-borderless` 去掉窗口标题栏（网页里铺满显示时不露边框，关窗口用任务栏）；页面采集已设 `cursor:never`，鼠标不会入画。

- 弹出独立窗口 CYBER-CAM，就是手机后置摄像头的实时画面（延迟 <150ms，USB 有线，比 Wi-Fi 稳）
- 换摄像头：`--camera-id=0..4`（0=主摄 1=前置 2/3/4=超广/长焦，`--list-cameras` 可查）
- 变焦：窗口聚焦时 Ctrl+↑/↓；开手电筒：加 `--camera-torch`

### 第 3 步 · 打开演示页

```
http://127.0.0.1:8100/?cam=gdm
```

- 页面**默认就是「窗口采集(scrcpy)」模式**：一键启动（bat/launch_demo）时浏览器带自动选窗参数，零点击进画面
- 手动开浏览器访问时：页面加载会弹一次「选择要共享的内容」→ 选 **CYBER-CAM** 窗口即可
- 页面连上桥后自动下发演示配置（raw 1 / dbg 1 / dump 0），波形和心率直接出来

### 一键启动（可选）

双击 `启动演示.bat`：环境体检 → 自动装缺依赖 → 串口桥 + scrcpy 相机窗 + 浏览器演示页。

## 2. 演示页功能速览

**布局**：左列 = 波形（大）上 / 数据（BPM·状态·信号条·速率）下；右列 = 摄像头整列。

| 区域 | 内容 |
|---|---|
| 波形卡（左） | min~max 包络带 + 中线，时间轴 = seq×5ms（固件权威时基），5/10/20 秒窗口可切 |
| 摄像头卡（右） | 四模式：MJPEG 网络流 / 本机摄像头 / 窗口采集(scrcpy) / 关闭；可镜像 |
| BPM 大字 | 心跳随 `beat` 位闪动（数字+红点+logo 同步脉冲）；**0 = 未出数，属正常** |
| 状态灯 | GOOD 绿 / WEAK 黄 / IDLE 灰 / VIB 橙 / OVER 红 / SRCH 蓝 |
| 信号条 | p95（黄线=质量门 45）、p50（黄线=18）、CV（黄线=0.12）；p95 越大耦合越好 |
| 元数据 | 数据速率（正常 ~195-205 行/s）、波形点数、CPU 占空、运行时长 |
| 命令栏（左下常驻）| 「常用命令」下拉 + 自由输入框；命令清单在 **commands.json**，改完刷新页面即生效（支持分组、分号多命令）|
| 控制台（点击展开）| 快捷按钮矩阵 / 自动配置开关 / Web Serial 接入 / 日志 |

演讲技巧：点「⛶ 全屏演示」；灯效开「彩虹」配合摄像头特写效果最好。

## 3. 手机摄像头三条路线对比（调研结论）

| 路线 | 做法 | 依赖 | 开源 | 延迟 | 推荐度 |
|---|---|---|---|---|---|
| **A. scrcpy 相机（已采用）** | 开发者模式 USB 调试 + `--video-source=camera`，网页 getDisplayMedia 采窗口 | scrcpy 5.0.1（Genymobile，MIT）| ✅ GitHub ★14万 | ~100ms 有线 | ★★★★★ |
| B. MJPEG 局域网流 | 手机装 IP Webcam(:8080) / DroidCam(:4747) / RemoteCam，网页 `<img>` 直连 | 任一 App，同 Wi-Fi | RemoteCam 开源(★776, MIT) | 200-500ms | ★★★★（无 USB 时的备选）|
| C. 虚拟摄像头 | DroidCam/OBS 客户端造 Windows 虚拟设备，网页 getUserMedia 选它 | 客户端软件 | 部分 | ~150ms | ★★★ |
| D. 笔记本摄像头 | getUserMedia 默认设备 | 无 | — | 0 | ★★（拍不到特写）|

要点：
- **小米/HyperOS 无官方「手机当电脑摄像头」通道**（妙享中心只做投屏/传文件；Windows 11 手机连接的相机功能也不支持小米），开发者模式 + scrcpy 就是事实标准方案
- scrcpy 相机要求 **Android 12+**（本机小米 15 / Android 14 ✓）；走 ADB shell 权限调 CameraManager，**无需 root、无需额外授权**，USB 调试授权即可
- 若某台小米开 USB 调试要求登录小米账号+插 SIM，那是 MIUI 对「USB 调试(安全设置)」的限制，基础 USB 调试不受影响
- 开源仓库：`github.com/Genymobile/scrcpy`（主力）、`github.com/Ruddle/RemoteCam`（MJPEG 备选）、`HunterAP23/ADB_Forwarder`（ADB 转发参考）

## 4. 演示前 Checklist（打印这份照着过）

- [ ] U 盘 `课堂演示/` 已拷到讲台机；板子 USB、手机 USB 已插
- [ ] 双击 `启动演示.bat`，体检全绿（有黄项按提示处理）
- [ ] CYBER-CAM 窗口有画面；浏览器自动打开，右上角两盏灯全绿
- [ ] 波形在动（速率 ~200），无手指时 state=IDLE 属正常
- [ ] 手指按传感器：p95 上到 45~200、state 变 GOOD、BPM 出数（3.5 秒冷启动）
- [ ] 控制台点「灯效:彩虹」，灯带随心跳动
- [ ] 点「⛶ 全屏演示」
- [ ] 备用：`dump 0` 已自动下发；若画面卡住重开一次浏览器页

**讲解口径**：波形每 5ms 一根线（200/秒）；BPM 是峰间隔中值滤波的结果，有 CV 质量门；运动伪迹为什么不靠谱——见 `D4-运动伪迹机理分析.md`。

## 5. 故障排查

| 症状 | 原因 | 解法 |
|---|---|---|
| 页面「串口未连接」 | 桥没跑 / 板子没插 | 跑桥；看桥窗口是否报「未找到 USB-Serial-JTAG」；拔插 USB |
| 波形停了但页面连着 | 设备静默（g_quiet 残留）| 桥 8 秒自动 rec wake；或控制台点「rec wake」 |
| 每次连串口板子重启 | DTR/RTS 复位 | 桥/Web Serial 都已规避；别用串口助手直开 |
| CYBER-CAM 窗口黑/秒退 | USB 调试未授权 / 手机端弹窗没点 | 拔插 USB，手机上点「允许」；`adb devices` 看是否 unauthorized |
| 窗口采集弹窗里没有 CYBER-CAM | scrcpy 没启动 | 先跑第 2 步再切 gdm 模式 |
| 页面采集一直无响应 | CYBER-CAM 被**最小化**（Chromium 采集列表不含最小化窗口）| 还原 CYBER-CAM 窗口，模式下拉切「关闭」再切回「窗口采集」|
| 采集画面全黑 | 手机熄屏/锁屏时 ADB 相机输出黑帧 | 点亮解锁手机；启动命令已带 `--stay-awake` 防休眠 |
| MJPEG 连不上 | 不在同一网络 / 端口错 | 手机和电脑连同一 Wi-Fi（或手机开热点电脑连）；IP Webcam=8080 DroidCam=4747 |
| 画面进了但页面被挤压 | 窗口太窄 | 拉大浏览器窗口；摄像头面板可承受 4:3/16:9 任意比例 |
