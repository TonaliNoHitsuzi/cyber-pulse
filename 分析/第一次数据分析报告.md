## 二、分析方法

### 2.1 指标定义

| 指标 | 定义 | 来源 |
|---|---|---|
| `rest_w` / `post_w` | 跑前 / 跑后即刻心率 | 手表 |
| `dev_rest` | 跑前段设备输出中位 | 设备 |
| `HRR60` / `HRR120` | 跑后即刻 − 60/120 秒时心率 | 模型 |
| `τ` | 指数拟合时间常数 | 波形轨迹 |
| `intensity` | 运动段加速度 σ 均值 | IMU |
| `>2g 占比` | 高强度时间比例 | IMU |
| 步数 / 步频 | 峰值检测 | IMU |
| 速度 / MET | 步频×步幅 → ACSM 公式 | 推算 |

### 2.2 心率轨迹提取

```
1 kHz（或 100 Hz）波形
  → 0.8–4 Hz 带通（去漂移）
  → 20 s 窗、5 s 步进、Hann 窗
  → 谐波和（f + 0.5·2f + 0.25·3f）
  → Viterbi 平滑（±0.12 Hz/帧）
  → 心率轨迹
```

### 2.3 建模

```
HR(t) = HR∞ + (HR0 − HR∞)·e^(−t/τ)
HR0 = 手表跑后即刻    HR∞ = 手表跑前静息
τ   = 由轨迹形状拟合（与倍率无关）
```

## 五、关键结论与可信度

### 结论 1（可信度高 · A）：数据链路可用
任务号配对 8/8、采样率偏差 <0.3%、零丢块、双源对齐 0.0s。
**可以支撑批量采集。**

### 结论 2（可信度高 · A）：设备在静息段可用，跑后段失效
静息 MAE 5.2 bpm；跑后 112~152 时设备只报 78~81。
**边界明确、可复现、可写进报告。**

### 结论 3（可信度高 · A）：100 Hz 足够
100 Hz 与 1 kHz 轨迹 RMSE ≤ 4.3 bpm。
**后续实验不必依赖电脑和 1 kHz 采集。**

### 结论 4（可信度中 · B）：BMI 与跑后心率同序
4 人 BMI 排序与跑后心率排序完全一致（ρ=1.00）。
但 n=4，完全同序的偶然概率约 4%，且速度差异仅 3%。
**属于"强提示"，需扩样验证。**

### 结论 5（可信度中 · B）：BMI 与恢复速度同序
τ 42→45→65→65 随 BMI 上升（ρ=0.95）。
但 τ 对窗口敏感，**建议改用 HRR60 作为主指标**（HRR60 与 BMI 相关性反而弱，ρ=0.40）。

### 结论 6（可信度低 · C）：运动形式影响曲线形状
慢跑为单相立即下降；冲刺出现 30 秒滞后。
但冲刺组轨迹幅度仅 69→66，**样本与幅度都不足，只能作为现象记录**。

### 结论 7（可信度高 · A）：运动量与心率反应脱钩
步数、距离、速度、MET 与跑后心率 ρ ≤ 0.40。
**混合运动形式下，"做了多少"不能预测"心率反应多大"。**

## 七、局限

1. **n=4**，所有相关系数置信区间极宽。
2. **运动形式不统一**（3 慢跑 + 1 冲刺），负荷不可比。
3. **手表只有两个锚点**，恢复曲线的绝对值依赖模型。
4. **耦合衰减**：5 分钟 p95 下降 7~17/min，后段数据质量下降。
5. **天气无方差**（同小时同地点），无法分析。
6. **传感器不绑带**（固定前提），耦合依赖手压。
