第一幕 · 01–03

先建立“信号长什么样”的直觉，再拆穿一个最危险的假象：没贴人也能出数。核心是“先量有没有劲，再决定信不信”。

第二幕 · 04–07

从“能不能信”的状态机，到会猜会改口的卡尔曼、看整段形态的模板、三路证据融合。讲清为什么高心率不能靠打补丁。

第三幕 · 08–12

把算法装进真实系统：BLE 数据链、三明治机构、同刻对照验收；最后拆成 D4 时基/CV 与四个边界。

先看这个 · 8 个词，用生活话解释
dev

把波形“翻正”，只问离平常水位多远。上涨、下跌都变成一个正数。

像水位报警器：只看离开正常水位多少。
p95 / p50

p95 是血管主路径的强度，p50 是底噪水平；两个都够，信噪比才够。

像看体检报告：最高血压和平时血压都要看。
隔峰 i+2

早期双源测量会出现两个鼓包（主峰 + 第二峰）；只数第一路，跳过一个再配对。

两个人交替敲门，只数其中一个人的节奏。
NCC（形态分）

拿一张“标准心搏照片”去比对整段波形，给 -1 到 1 的相似度。

像把透明标准答案盖在答卷上逐格对。
卡尔曼

先按“变化速度”猜下一拍在哪，再用真实测量修正；也承认自己不确定。

像导航：先按车速推测位置，再用路口纠正。
先验 / 似然 / 后验

事先的猜测 / 两路证据各自的可能性 / 综合后的判断。

三个证人指同一个点，光斑重叠处最亮。
容积传导

心脏的震动沿血管、肌肉、骨骼多路径传到同一点；血管最快最强，构成主峰。

同一句话的直达声先到，其他路径像回声后到。
信噪比

主路径的信号 vs 其他路径/底噪。按压力度，本质上就是在调这个比值。

不是越用力越好：压扁主路径，噪音还在。
