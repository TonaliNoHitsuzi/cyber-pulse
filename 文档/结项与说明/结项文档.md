> 单片机课程设计 · 第 22 组

> 周期：2026-10-29 ～ 2026-11-08（Day 1–7 工程，Day 8 收尾）

## 一、项目概况

做一个能戴在手腕上的脉搏检测系统：压电薄膜采脉搏引起的体表微振动，ESP32-C3
完成采样、检峰、心率解算与显示，手机 App 看波形和数据；课程汇报用一套 117 页的
网页讲稿，现场用本机演示平台展示实时波形、BPM 和手机后摄。

目标不是做出医疗级设备，而是把「传感器 → 采集 → 算法 → 系统 → 实验」这条链
完整走一遍，并把每个环节为什么这么做讲清楚。

## 三、系统与最终结果

### 3.1 硬件

- **传感器**：PVDF 压电薄膜，电荷源 + 约 1.1 nF；靠电阻转电压形成 RC 高通，
  τ≈0.55 s（fc≈0.29 Hz），静态压力测不了，只响应动态搏动。
- **主控**：ESP32-C3；ADC 1 kHz，5 样本窗口取 min/max → 200 行/s。
- **外设**：OLED（3V3）、16 颗灯珠、按键、4 MB 闪存；电池盒 / 充电宝两套供电。
- 结论：能稳定采到 BCG 波形与心率；跑步场景受运动伪迹限制（见 3.3）。

### 3.2 算法与系统

- 检峰：350 ms 不应期 + 隔峰 i+2 + 中值；七种质量状态，只有 GOOD 出数。
- 质量门：p95≥45 且 p50≥18；输出端门控，避免丢峰断链。
- 判据：真实 CV ≤0.05，噪声锁定 >0.15（阈值 0.12）。
- 系统：BLE 100 Hz 波形流 + 历史补发（按序号去重）；4 MB 闪存按 1 kHz 存全档，
  约 26 分钟；导出走十六进制文本通道，规避控制台行尾转换。
- 演示平台：`127.0.0.1:8100`，左波形、中 BPM/状态/质量门、右手机后摄。

### 3.3 关键数字（可追溯）

| 指标 | 结果 |
|---|---|
| 静息心率 MAE（4 人） | **5.2 bpm**（77/77、75/80、82/79、89/76） |
| 跑后设备读数 | 78–81 bpm（手表 112–152）→ 跑步模式**不可用** |
| 检峰硬上限 | **85.7 bpm** = 60/(2×0.35) |
| 采样率 | 100 Hz 与 1 kHz 的 RMSE ≤4.3 bpm，τ 差 0–7%（3/4 人） |
| 降速时间常数 τ | 42 / 45 / 65 / 65 s（R² 0.97 / 0.94 / 0.77 / 0.72） |
| 相关性（n=4，B 级） | BMI↔跑后 ρ=1.00；BMI↔τ ρ=0.95；运动量↔心率 ρ≤0.40 |

## 五、局限与未完成

1. **跑步模式未解决**：峰重叠（不应期 60/(2×0.35)=85.7）与步频耦合（主频=步频/2）
   叠加时不可解；设备在跑步时读到的是步伐，不是心跳。
2. **硬件升级只到分析**：差分对导联、电荷放大器做成方案与讲解页，未实际改板。
3. **样本量小**：4 名受试者、每人静息与跑后各一次；相关性结论为 B 级，只能当
   现象描述，不能当统计结论。
4. **无临床标定**：手表只作绝对基线（每人 2 次），未做逐搏对照。
5. **100 Hz 结论来自离线重采样**，未在固件里改成 100 Hz 实测。

## 八、结论

课程要求的三件事都完成了：能采（1 kHz、BCG 波形）、能算（静息 MAE 5.2）、
能讲（117 页讲稿 + 现场演示）。系统在静息场景可用，跑步场景诚实地标为不可用，
并把原因（85.7 上限、步频耦合、叠加不可解）作为项目的主要工程结论。

后续如果继续做，优先级是：差分对导联 + 电荷放大器改板 → 跑步场景重测 →
100 Hz 固件化 → 扩大样本。
