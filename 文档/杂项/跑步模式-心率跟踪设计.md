# 跑步模式心率跟踪设计（v1 草案）

> 目标：静息(43~120)与跑步(120~180)统一处理，且**加速区间（HR 爬升段）要如实跟踪**，不能为了稳而抹平。
> 约束：测试机会稀缺 → 设计必须自带兜底与可离线验证路径。

---

## 1. 为什么"只改上限"不行（三个真实障碍）

| 障碍 | 现象 | 原因 |
|---|---|---|
| A. 双峰配对反转 | 高心率下 BPM 会**减半**（150→75） | 现有"隔峰(i+2)"是为静息时的重搏波设计的；心率升高后重搏波与主峰融合，i+2 跨了**两拍** |
| B. 中值窗口滞后 | 加速段显示落后 3~5 秒 | 9 样本中值在 150 BPM 也横跨 ~4 秒，且对单调爬升天然滞后 |
| C. 合理性过滤反噬 | 快速爬升时窗口内偏差>30% 被拒 → 4 次后清窗 → 断档 | 过滤假设"心率缓变"，与加速段矛盾 |

结论：需要**用"当前周期估计"来动态决定配对**，再用**带速度状态的卡尔曼**做平滑——两者共享同一个周期估计，互相自洽。

## 2. 核心设计

### 2.1 动态配对（解决 A）

- 峰值检测放宽：`PEAK_MIN_GAP` 350ms → **200ms**（让高心率下的真峰不被吞）
- 每个候选峰与"上一拍"的间隔 `d`：
  - `d < 0.55 × P_est` → **重搏波/噪声**，不计数（`P_est = 60000/hr`）
  - `d > 1.80 × P_est` → **漏拍**，跳过本次测量（保留计时）
  - 其余 → 有效拍，测量值 `z = 60000/d`
- 静息时 `P_est≈770ms`，重搏波（~250ms）被 0.55P=424ms 拦掉；
  跑步时 `P_est≈400ms`，重搏波（~200ms）被 220ms 拦掉，真拍（400ms）通过。
- **同一条规则覆盖全频段**，无需模式切换（不做"自适应套自适应"）。

### 2.2 匀速卡尔曼（解决 B、C）

状态 `x = [hr, v]`（心率、心率变化率），离散匀速模型：

```
预测:  hr += v·dt
       P  = F·P·Fᵀ + Q(dt)
测量:  z  = 60000/d          （来自有效拍）
       R  = (hr²·σ_t/60000)²  σ_t≈20ms 间隔计时误差 → 高心率时测量噪声自然变大
更新:  标准 KF
```

- `Q` 取 `σ_a = 2 BPM/s²`（允许跑步启动时 ~1.5 BPM/s 的爬升）
- 速度限幅 `|v| ≤ 8 BPM/s`，心率限幅 `[35, 210]`
- **输出 = x.hr**，不是中值——加速段由 v 外推，天然跟得上

### 2.3 兜底矩阵（测试稀缺的保险）

| 编号 | 场景 | 兜底动作 |
|---|---|---|
| F1 | 新息超 4σ（离群拍） | 丢弃该测量；连续 5 次被拒 → 用最新 z 重置滤波器 |
| F2 | 2.5s 无有效拍 | 状态置未初始化 → `SRCH`，BPM 显示 `---`（不显示陈旧值） |
| F3 | 质量门不过（p95<45 或 p50<18，带滞回） | 输出 BPM=0，**滤波器内部继续跑**（信号恢复立刻出数） |
| F4 | 速度长期贴限幅（|v|≈8 持续 3s） | 判为失控 → 重置（防发散） |
| F5 | 物理限幅 | hr 35~210、v ±8 BPM/s、d 300~1400ms 之外一律不计 |
| F6 | 上电/换人 | 首个有效间隔直接初始化，P0 方差给宽 |

### 2.4 参数表（可调，集中在一处）

| 参数 | 值 | 说明 |
|---|---|---|

| PEAK_MIN_GAP_MS | **200** | 350→200，为高心率让路 |
| IV_MIN_MS / IV_MAX_MS | **300** / 1400 | 43~200 BPM |

## 2.5 运动伪迹抑制（跑步的第二大障碍）

跑步时压电膜会同时收到：**足底冲击（步频 2.5~3.5Hz）**、手臂摆动（1~1.5Hz）、手套/线缆晃动。
幅度通常是脉搏的 3~10 倍，而且步频与心率频段**重叠**（180 spm = 3Hz，心率 150 = 2.5Hz），
所以"带通滤波"解决不了，必须走**形态学 + 统计 + 跟踪**三路。

### 分层门控（从便宜到贵，逐层否决）

| 层 | 判据 | 依据（实测） | 动作 |
|---|---|---|---|
| L1 饱和 | 窗口 min=0 或 max=4095，或跨度>3000 | 冲击会让 ADC 打满 | 整窗丢弃 |
| L2 陡度 | 单样本跳变 >300 counts/5ms | 脉搏上升沿 <100；冲击 >500 | 该峰不算拍 |
| L3 宽度 | 超阈连续段 ≤1 个窗口（5ms） | 静息真峰中位宽 2 窗；冲激 83% 宽 1 | 该峰不算拍 |
| L4 幅度一致性 | 峰幅与最近有效拍幅度中值偏差 >3× | 脉搏逐拍幅度变化 <1.5×；运动伪迹起伏极大 | 该峰不算拍 |
| L5 新息门 | \|z − hr_pred\| > 4σ（卡尔曼） | 伪迹拍必然偏离预测 | 丢弃该测量 |
| L6 节奏锁相 | 连续 5 个被拒间隔集中在 ±8% 且伴随尖峰 | 步频是稳定的周期源，会被误锁 | 判 `MOTION`，BPM 输出 0 |
| L7 状态诚实 | 以上命中任一持续 >1.5s | — | 屏幕/App 显示"运动干扰"，**不显示可疑数字** |

### 与卡尔曼的关系
L1~L4 决定"这个峰能不能喂给滤波器"；L5 决定"这个测量要不要采信"；
L6~L7 决定"要不要诚实地承认测不了"。四层是串联的，任何一层否决都不影响其它层继续工作。

### 机械层（零成本，优先做）
- 传感器压在**拇指腹**、外覆刚性小垫 → 手套与皮肤相对位移最小
- 线缆用胶固定，避免甩动（线缆晃动 = 1Hz 大信号）
- 跑步时手臂**贴身上举**（摆幅小），或把手插在口袋/腰包内

### 可选的下一版硬件
- 加 MPU6050（I2C 与 OLED 共用总线）：用加速度计做**参考通道**，
  以步频/臂摆相位做自适应对消（LMS）。这是可穿戴的教科书做法，但要占用 I2C 带宽与算力，
  留作 v2。

### 运动伪迹的验证（不需要真的跑步）
- **原地踏步 60s**（步频 150~170/min）：检查是否出现假 BPM、是否进入 MOTION
- **单臂前后摆 30s**：模拟臂摆
- **快速下蹲起立**：模拟大冲击
- 以上三个室内就能做，先把伪迹门调好，再上真实跑步

## 6. v2 修订（D3 夜里，基于离线仿真）

### 6.1 仿真暴露的两个硬事实
1. **噪声底不是常数**：同一批录音里，好耦合段 p50≈60、悬空段 p50≈8~12。固定阈值 40 在 p50=60 的
   录音里会把**全部噪声当成峰** → 这就是老数据"周期规律怪"的来源。
2. **真实波形结构**：每拍是一个 200~320 的大包络（含重搏波），拍间是 40~80 的噪声底；
   **不是**"等间距双峰"。此前"隔峰配对"能工作，依赖的是强制的 350ms 不应期把噪声挡在门外。

### 6.2 v2 架构（三层，各司其职）

```
① SNR 自适应阈值    thr = clamp(3 × p50, 30, 200)      ← 解决噪声底漂移
② 相位锁定取拍      每个预测周期只取一个峰（窗口 0.55P~1.35P）← 解决双峰/纹波重复计数
③ 匀速卡尔曼        [hr, v] 状态，测量=周期间隔          ← 解决加速段滞后
```
外加伪迹四门（饱和/陡度/幅度一致性/新息），全部在 ① 之后。

### 6.3 为什么"每周期只取一拍"是关键
- 自由峰值检测 → 一拍可能出 2~4 个峰（重搏波、纹波、噪声），配对逻辑必须猜"该隔几个"
- 相位锁定 → **根本不需要猜**：知道当前周期 P，就只在前一拍的 0.55P~1.35P 内找最大峰，
  一次周期必然只产生一拍；加速时窗口跟着 v 移动
- 代价：初始锁定需要一次好的周期估计（用 i+2 中值 + 自相关双重投票，见 6.4）

### 6.4 启动与重锁（兜底）
| 阶段 | 做法 |
|---|---|
| 冷启动 | 收集 4 个超阈峰 → i+2 中值（限 300~1400ms）→ 初始化 P |
| 锁丢失 | 连续 5 个周期窗口内找不到超阈峰 → 释放锁，回到冷启动 |
| 心率跃变 | 新息连续 5 次超 4σ → 用当前测量值重置 |
| 输出诚实 | 质量门不过 / 未锁定 → BPM=0（显示 `---`），绝不显示陈旧值 |

### 6.5 已验证 / 待验证
| 项 | 状态 |
|---|---|
| 悬空/空白对照（老数据）→ 不输出 | ✅ 仿真通过 |
| 静息合成信号（78 BPM + 5Hz 纹波）| ⚠️ 锁相正常，但启动期会受纹波干扰，需在真机录音上再校 |
| 加速段（80→155→90 合成） | ✅ 误差中位 2~3 BPM（阈值改用动态后） |
| 运动伪迹（步频 2.8Hz 大幅） | ⏳ 待与真机踏步数据一起验 |
| 真机跑动 | ⏳ 需现场 |

## 7. v3：蒙特卡洛仿真结论（D3 深夜）

### 7.1 搭了什么
`sim_robust.py`：从真实录音里**按拍切出心搏模板**→按目标心率重排→叠加噪声底/纹波/步频冲击/臂摆/掉线，
重复随机采样（幅度、噪声底、步频相位、素材随机）跑 N 次，统计：
稳态误差、加速段误差、锁定时间、伪迹误报率、掉线恢复时间。

### 7.2 仿真的三个关键判决
1. **"3×p50 自适应阈值"是错的**（我上一版的设计）：高心率时脉搏占空比变大，p50 被抬高，
   阈值逼近峰幅 → 大量漏拍 → BPM 减半。改成**低门限**（`max(20, 1.2×p50)`）后正常。
   → 结论：阈值只回答"有没有信号"，**真伪交给卡尔曼新息门**。
2. **相位窗口宽度**：`[0.55P, 1.35P]` 在 80~180 BPM 全部正确；放宽到 1.8P 会漂到次谐波。
3. **< 60 BPM 会锁到高次谐波**（低心率周期长，窗口相对太窄）。本项目使用场景（静息 70~90、跑步 120~180）
   **不受影响**，文档记为已知限制。

### 7.3 理想合成信号验证（无素材污染）
| 心率 | 输出中位 | 误差 |
|---|---|---|
| 80 | 83 | 3 |
| 120 | 120 | 0 |
| 160 | 159 | 1 |
| 180 | 187 | 7 |

（含 5Hz 纹波与噪声底）

### 7.4 用老录音做素材的教训
老录音（10-30 号）噪声底差异极大（p50 8~100），自相关估出的心率与真实值经常不符（如 224652 估 58 实际 79），
**不能作为真值素材**。蒙特卡洛的素材必须来自**新硬件的新录音**。

## 9. v4：把"速度"真正放进卡尔曼（原理化重构）

### 9.1 原理
一拍的时刻 = 上一拍 + 周期。周期由心率决定，而心率有速度。所以**下一拍时刻的不确定度**
必须由状态协方差沿时间传播得到：

```
σ²_next = p00 + 2·P·p01 + P²·p11        ← 含速度协方差 p01 与 p11
σ_P     = P · σ_hr / hr                  （P = 60/hr）
搜索窗口 = 预测时刻 ± 3·σ_P，并设 HRV 生理下限（5% 周期）
```

- 状态锁定时 σ_hr 小 → 窗口自动收窄（天然排除重搏波）
- 速度不确定时 p11 大 → 窗口自动放宽（允许快速变化）
- **不再是固定 0.55P~1.35P**（那等于把"心率不变"写死进窗口）

### 9.2 三个配套决定（也都是原理，不是补丁）
| 项 | 做法 | 理由 |
|---|---|---|
| 过程噪声 Q | σ_a = 2~4 BPM/s² | 运动中 HR 最大变化率 ~2 BPM/s，加速度噪声取 2~4 |
| 门控 | **绝对阈值 45 BPM/拍**（非 4σ） | σ 门会拒掉真实变化（滤波器自信时 σ 很小）；单拍变 45 BPM 生理上不可能，这才是伪迹判据 |
| 落空处理 | 窗口按 25% 逐级放宽到 1.95P，连续 3 次落空则重置 | 减速时真拍会晚到；放宽是"等待"，重置是"重新识别" |

### 9.3 仿真结果（8 种速度模式 × 6 随机种子，中位）
| 速度模式 | MAE(BPM) | 说明 |
|---|---|---|
| 指数上升 τ=5s | **2.4** | 优秀 |
| 冲刺循环 90↔170 | **6.8** | 优秀（含 10 BPM/s 的快速变化） |
| 正弦调制 100±30 | **6.4** | 优秀 |
| 线性 80→160/20s | 13.4 | 启动段拖累 |
| 双段 80→110→160 | 20.3 | 第二段启动偏慢 |
| 阶跃↑ 80→160 | 23.4 | 1s 收敛 |
| 阶跃↓ 160→80 | 60.4 | 未恢复（见下） |
| 随机游走 ±10 | 72.5 | 本轮退化（种子间方差大） |

### 9.4 两个仍未解决的原理性问题（诚实记录）
1. **启动锁定**：目前三种方法（i+2 中值 / 自相关 / 主峰间隔）在不同素材上各有胜负，
   没有一种在纹波+噪声下稳定。这是当前最大误差来源（多数"大误差"都发生在启动后 10s 内）。
   → 结论：**启动需要更长的观察窗（建议 6~8s）+ 两法投票**，且必须用真实素材定参。
2. **阶跃下降不恢复**：心率瞬间腰斩时，旧相位窗口内只剩重搏波，会一直锁重搏波。
   生理上不会发生，但**恢复慢**意味着真实场景里"跑后骤停"要几秒才回正。
   → 结论：接受（有 3 次落空重置兜底），不为此再加补丁。

### 9.5 结论
结构（含速度的卡尔曼 + 协方差导出的窗口 + 绝对伪迹门）是原理正确的；
**待定的只有"启动锁定"和少数参数**，而这两项必须用新录音定，不能继续用老数据过拟合。

## 10. 决策：新算法不默认启用（对老数据的保护）

### 10.1 原则
老方法（thr 40 / 350ms 最小间距 / 隔峰i+2中值 / ±30%合理性过滤 / 质量门）是**已验证基线**。
新算法只作为**可编译开关**存在（`USE_TRACKER`，默认 0），任何会强烈改变老方法行为的改动一律回退：
- 峰值最小间距：200ms → **退回 350ms**（200ms 会把重搏波当峰，启动即锁错）
- 配对方式：相位锁定 + 卡尔曼 → 只在 `USE_TRACKER=1` 时生效
- 阈值：退回固定 40（自适应阈值会改变老数据的行为）

### 10.2 顺带修掉的真 bug（老方法也存在）
`intervals[]` 是固定 9 长度的环形数组，新间隔插在**尾部**，但取值时复制的是**前 n_iv 个**：
前期有效区间少时，复制到的全是初始 0 → `60000 / 0` → 输出 `-1`。
修复：一律取尾部 `intervals + (BPM_MED_N - n_iv)` 起的 n_iv 个。

### 10.3 回归验证
| 检查 | 结果 |
|---|---|
| 悬空 10s | `bpm=0`（修复前出现过 `bpm=-1`）|
| 离线复算 ★验证会话（历史 78.4）| 83.0（差 4.6，属镜像实现误差）|
| 弱耦合会话 | 质量门正确输出 0 |

### 10.4 下一步
到设备旁做一次 20 秒按压，确认现场读数回到 76~80 且无 `-1`；
再谈是否用新录音开启 `USE_TRACKER`。

## 12. 统一框架：峰检测就是"脉冲模板匹配"

### 12.1 认识
原始峰检测 = 用"尖峰模板"做匹配（局部极大 + 阈值），本质是**最简单的模板匹配**。
所以模板匹配不是替代方案，而是把同一框架从"像不像尖峰"升级成"像不像一次完整心搏"。

正确结构是**三级串联，各解决一个问题**：

| 层 | 作用 | 解决什么 |
|---|---|---|
| ① 峰检测（脉冲模板） | 事件触发，便宜 | 候选点 |
| ② 心搏模板 NCC 校验 | 形态放行/否决 | 重搏波、纹波、冲击伪迹 |
| ③ 动态配对 + 卡尔曼 | 测时与平滑 | 高心率下 i+2 配对失效、加速段滞后 |

### 12.2 实测：只加②会发生什么（仿真）
| 场景 | 真拍保留率 | i+2 中位 | 得出 BPM | 真值 |
|---|---|---|---|---|
| 理想 80 | 102% | 1120ms | 54 | 80 |
| 理想 150 | 100% | 800ms | **75** | 150 |
| 纹波 150 | 100% | 800ms | **75** | 150 |

结论：**②能把伪峰挡掉（真拍保留率接近 100%），但救不了高心率配对**
——心率高时重搏波与主峰融合，i+2 跨了两拍，直接给出半值（150 → 75）。
这正是第 ③ 层（用当前周期动态配对）不可省略的证据。

### 12.3 模板来源
- 当前用**参数化模板**（收缩峰 + 重搏波 + 舒张拖尾），零外部依赖
- 上线后可**在线自适应**：只用 NCC>0.8 的段做指数更新，避免伪迹污染
- 数据不足时的补充：公开脉搏波形数据集（PhysioNet 的 PPG/ABP、MIMIC 波形段）可提供
  不同年龄/部位的形态先验；但这些数据是光电容积/血压波形，压电膜形态需再做一次尺度对齐

### 12.4 现状与建议
- 出厂固件仍是老方法（静息 43~120 BPM，已验证 78 BPM/σ=0）
- 跑步模式 = ①②③ 全栈，需要在真机新录音上定参（②的 NCC 阈值、③的窗口与 Q）
- 不建议在缺新数据时把 ①②③ 硬塞进出厂固件

## 13. 贝叶斯融合（在卡尔曼框架内）

### 13.1 形式化
卡尔曼每拍给出**先验**：下一拍时刻 `t ~ N(t̂, σ²_pred)`，其中 σ²_pred 由协方差沿时间传播
（含速度项）。两个探测器各自提供**似然**：

| 来源 | 观测 | 似然写法 |
|---|---|---|
| A 峰检测 | dev 幅度（信噪比） | `L_A(t) = exp(−(z_thr − z(t))⁺ / s_A)`，z 为幅度 z-score |
| B 模板匹配 | NCC 分数 s(t) | `L_B(t) = σ(k·(s(t) − s₀))`，s₀ 为形态合格线 |

后验：`p(t | 观测) ∝ 先验(t) · L_A(t) · L_B(t)`，在预测窗口内取 argmax 作为**拍的估计**。

### 13.2 为什么这比"二选一/加权"好
1. **R 自动得出**：用拉普拉斯近似，`σ²_meas = 1 / (−d²ln p / dt²)`，
   证据越尖锐（两个探测器都锐）→ R 越小 → 滤波器更信测量；证据平缓 → R 大 → 更信预测。
   这正好替代我们之前手调的"固定 R + 卡方门"。
2. **优雅降级**：任一路失效（幅度低 / 形态差）时，另一路仍能支撑；两路都弱 → 后验峰不显著 →
   本拍不出测量（coast），这就是天然的"诚实输出"。
3. **互补性被显式利用**：峰检测强在时域锐度，模板强在积分类信噪比。乘积融合让
   "时域有个峰"和"整周期像心搏"同时成立才被采信。

### 13.3 工程实现（MCU 代价）
每个预测窗口（±20%P ≈ 100 个窗口点）：
- 算 dev 的幅度似然：O(100)
- 算 NCC：100 个点 × 模板长度 150 → 1.5万 MAC
- 相乘取 argmax、算二次差分得 σ²：O(100)
总计每拍约 2 万次乘加，160MHz 下 <1ms，完全可接受。

### 13.4 现状（诚实记录）
- 设计已完成，**原型代码还在调试**：当前 Python 里 NCC 的最大值能到 0.78（说明形态确实可对齐），
  但检测器输出接口有 bug（返回 0 个峰），所以还没有可信的"召回/精确率"对比数字。
- 修好后的验证清单：
  1. 单探测器 vs 贝叶斯融合的 召回/精确率（干净/噪声/纹波/冲击 五档）
  2. 融合后的 R 是否随场景自动变化（应当：干净时小、冲击时大）
  3. 与老方法在★验证会话上的 BPM 一致性
- 仍然保持 `USE_TRACKER=0`，不影响出厂固件。

## 14. 运动伪迹的应对（D4 文献调研 + 预实验）

### 14.1 文献路线图
| 方法 | 出处/思想 | 对本项目 |
|---|---|---|
| **TROIKA**（Zhang et al., IEEE TBME 2014, arXiv:1409.5181）| SSA 去趋势 + 稀疏谱重建 + **加速度约束下的谱峰跟踪**（心率变化受运动强度约束） | 最对口（手腕 PPG 剧烈运动测 HR 的标准框架）；计算重 → 离线分析用 |
| **自适应参考对消（LMS/RLS）** | 加速度计做参考通道，自适应减去运动分量 | 手机 IMU 与手套不在同点，相关性打折；固定跑姿下可用 |
| **小波阈值收缩（minimax）** | Donoho-Johnstein：细节系数 minimax 阈值软收缩 | 即"minimax 筛除"；对高频冲击有效，但见 14.2 的预实验 |
| 多通道/深度生成模型 | 多传感器或学习先验 | 单通道，不适用 |

### 14.2 预实验（合成冲击 + 真实脉搏）——一个诚实的负结果
用 ★会话真实脉搏 + 悬空库尖峰按 2.8Hz 步频注入（避开真拍 ±150ms，3 样本宽，250~600 幅度）：

| 处理 | 脉搏命中 | 伪迹误检 |
|---|---|---|
| 未去噪（老方法原样） | **56/56** | **0** |
| 幅度门（>500 置零） | 56/56 | 0 |
| 小波 L2/soft | 3/56 | 44 |
| 小波 L3/soft | 0/56 | 26 |
| 小波 L4/soft | 1/56 | 29 |

**三条结论**：
1. 该合成强度下，老方法的 **350ms 不应期已天然吸收冲击**（冲击落进前一拍的不应期）——伪迹没有想象中致命
2. 小波 minimax（朴素实现）**σ 被冲击能量抬高 → 阈值过大 → 把脉搏也杀了**（命中 0~3/56）。
   要用必须做"分段 σ 估计 + 只收缩高频带"，且阈值不能由含冲击段驱动
3. **合成冲击无法复现真实跑动的手套耦合波形**——一切定论必须等实测

### 14.3 三层应对架构（定了）
| 层 | 手段 | 状态 |
|---|---|---|
| 板载实时 | 已有伪迹四门（饱和/陡度/幅度一致性/新息）+ 350ms 不应期 | ✅ 已在固件 |
| 手机准实时 | **IMU 步态同步门控**：落地 ±80ms 标记不可信；步频通道供对齐 | ✅ IMU 采集已实现（50Hz 加速度+陀螺仪+步检测+步频） |
| 离线分析 | TROIKA 式谱跟踪做地面真值；小波做对照实验 | ⏳ 等实测数据 |
