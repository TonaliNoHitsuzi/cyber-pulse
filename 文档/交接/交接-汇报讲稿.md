## 3. 规范与约定（含大量踩坑）

### 3.1 视觉
- 逻辑画布 1600×900，缩放用纯 CSS `transform:scale(min(100vw/1600,100vh/900))`
- 冷白主题：`--bg #fbfcfe --txt #0f172a --dim #64748b --blue #1d4ed8 --orange #ea580c --teal #0f766e --red #b91c1c --violet #6d28d9`
- 五条线：硬件=蓝/芯片、算法=橙/波形、实验=青/烧瓶、组织=紫/人、**系统=天蓝/屏幕**（原「演示」线更名，Day3 起 BLE/App/屏幕都归它）

### 3.2 组件（deck.js）
`h/p/ul/quote/stats/table/badge/figure/figures/chart/compare/steps/formula/note/echo/annot/split/matrix/transition/dag/html`
- 任意块加 `"frag": true` 即逐条出现（`ul/steps/stats` 是逐条，容器不再整体淡入）
- `split` 里的块各自 frag，转场矩阵/时间轴这类图不要 frag 到容器
- 文案里 `**粗**`、`` `代码` ``、`[[页面id|文字]]` 跳转

### 3.3 动画工作流（现行）
新建页**直接加 frag**，然后跑：

```bash
python tools/check_anim.py      # 逐页 frag 数，没加动画的标 ** 没动画 ** 并返回非零
```

它会递归 `split`，自动跳过转场页、占位页（含「待补」）、纯图页（bare）。**每页收工前必须跑一次**。

### 3.4 转场（renderers/transition.js）
- 矩阵 → 按 → 镜头推进（viewBox 900ms）→ 展开本节清单
- **冻结窗格**：Day / 线名变成小胶囊，位置每帧按 `viewBox` 投影反算，始终贴住焦点格，最后停在画面边缘
- **进节动画**（deck.js）：上一页 `scale .94 + opacity 0` 收拢淡出 220ms → 新页从 `scale .88` 放大淡入 400ms
- 调试态：`?stage=matrix`（看矩阵）、`?stage=zoom`（看缩放末帧）、`?auto=N`（启动后自动前进 N 页）

### 3.4b 总览与定点跳转（2026-11-06 新增）
- 右上角固定「总览」按钮 + `G`：打开**按天×线分组**的页面总览（目录表格页自身不显示按钮）
- 总览里点某页：先在全屏播放目录矩阵的镜头推进动画（定位到 Day×线），列表高亮该页，停约 1 秒后再跳转
- 实现：**直接复用节转场的 `renderTransition`**（`autoplay / autoDelay / arriveDelay / onArrive / counts` 选项），定位层在 `index.html` 的 `#locator`，节标题也取自对应转场页
- 转场取景窗必须与容器**同宽高比**（否则 SVG meet 留边，标签和裁切会错位）；相机开跑时表头文字整体淡出，只留 Day/线名两个冻结胶囊
- 右上角按钮是**开/关 toggle**：点开进总览（矩阵视图），再点变「返回」回到当前页——所有页都有（含目录页），固定在右上、浮在总览之上
- 总览内部还有**矩阵 / 列表**两个视图：header 里的 toggle 按钮文案随动作变（「切换为列表视图」/「切换为矩阵视图」），旁边有「当前：矩阵视图」选中态；切换用 170ms 淡出淡入
- 调试：`?ov=1` 开总览、`?ov=list` 直接列表视图、`?loc=7,demo` 定位跳转、`?click=N` / `?wheel=N` 合成翻页

### 3.5 echo（跨天呼应）
内部名 echo，屏幕禁止出现"伏笔/铺垫/应验"。一句 ≤30 字、问句或断言；画面正中；从上方飞入；**必须是本页最后一步**。

### 3.6 底部 HUD
右下角是**本节剩余页数**（按 day 分段，遇到转场页断开），不是页码点。页码在最右。

### 3.7 CSS 冲突（重要的坑）
所有页的 `page.css` 启动时**全部注入**。现行规则：`renderSlide` 把当前页 `<link>` 移到末尾，并把其余页的 `media` 设为 `not all`（**不要用 `link.disabled`，Chrome 下不生效**，实测禁用了规则仍匹配）。这样每页只吃自己的 page.css。**新页的 page.css 仍不要写全局过窄选择器（如 `.fig>svg`），尽量带页内容器类。**

### 3.8 其它实现细节
- 页内资源写 `"src":"assets/x.jpg"`，deck 自动改写路径
- JSON 文案里**不能用英文双引号**，用「」或“”
- 截图：headless Chrome 必须加 `--force-device-scale-factor=1`，否则内容只有一半大
- 截图开关：`?anim=0` 关动画；`?anim=0&reveal=1` 全部展开（截图用）
- 桌面来图：**复制进 `pages/<slug>/assets/`，删掉桌面原件**（用户明确要求过两次）

## 5. 已定稿的内容事实（写页时直接用，别再推导）

### 5.1 硬件/采样
- 压电膜 = 电荷源 + ~1.1 nF；必须靠电阻转电压 → RC 高通，τ≈0.55 s，fc≈0.29 Hz
- 1 kHz / 5 样本窗口取 min/max → 200 行/s；10 kHz 会自激
- 内部双拉必须在 `adc_continuous_start()` 之后设
- 引脚：ADC=GPIO0、SDA=8、SCL=10、按钮=4、灯带=5；OLED 只吃 3V3；电池进 5V
- 两套供电：电池盒（带开关、轻）/ 充电宝+电源模块（稳、采集用），二选一进 5V

### 5.2 生理
- BCG 定义（官方）："记录每次心跳血液射入大血管引起的人体重复性运动，画成图形"；70 mL / 1~10 µm / 10⁻³ g；Starr 1939
- 血管：压力波 5~10 m/s，分叉反射 → 主波 + 重搏波，间隔 0.3~0.4 s（实测 380 ms）
- 谐波：不同介质阻抗不同 → 界面反射；血液是主通道

### 5.3 Day3 质量体系
- 七个状态：GOOD/WEAK/IDLE/SRCH/VIB/OVER/MOTION；只有 GOOD 出数；门 p95≥45 且 p50≥18
- 力没有牛顿标定 → 用"中线"当力计，中线 ≥2600 即过压
- 悬空假心率 118 s → 加质量门 → 0 s
- 门加在检峰会丢峰断链（56）；改为输出端门控，中值窗口 7→9，σ 6.1→0.7
- 状态抖动：质量优先判决 + p95 平滑 τ≈2 s，GOOD 占比 91%~100%
- 补发：缓冲+按序号+App 去重；20 批/s × 202 B ≈ 4 KB/s（10 倍）；射频耦合抬底噪 p50 5~13 → 18~20；门槛 18→30；57 帧零假阳性

### 5.4 Day4 的 78（三页一条链）
1. **时间戳塌缩**：模板匹配每 500 ms 占 15 ms + 每 5 s 1 KB 打印 → 滞后 217 ms；卡顿期 ADC 堆积，恢复后时间戳几乎相同 → 恒 78；修成 seq×5ms → 72~84
2. **不应期锁定**：悬空时噪声一过 350 ms 就补峰，间隔被钉在 gap；参数扫描 300→600 输出 78→52；min/max 是峰值保持、基线 τ≈4 s 跟得慢
3. **合账**：假峰 + 不应期 + 时间戳塌缩 = 一个常数；78 正好在正常区间所以没被怀疑
- CV 门：真实 CV ≤0.05，噪声锁定 >0.15（尖峰+长尾），阈值 0.12
- 冷启动：≥5 个间隔；3.5→4.5 s；11 段首数误差平均 2.7、最大 8、8/11 在 ±3 内
