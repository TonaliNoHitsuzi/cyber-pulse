## 2. 闪存文件格式

```
[16 字节头]
  0-3   "CPLS"
  4     版本 1
  5     保留
  6-7   fs (uint16 LE) = 1000
  8-11  起始板载毫秒 (uint32 LE)
  12-15 保留

[数据块，重复]
  0-3   板载毫秒 (uint32 LE)
  4-5   样本数 n (uint16 LE)，正常 1000
  6..   n × int16 LE（ADC 原始值 0~4095）
```

**校验**：块时间戳间隔中位 1016ms → 实际采样率 984Hz（离线分析用时间戳校正）。

## 3. 回传协议（请求-应答）

| 命令 | 作用 | 回显 |
|---|---|---|
| `rec open <n>` | 打开 recNNN.raw | `FILE\|OK\|<size>` 或 `FILE\|ERR` |
| `rec rd <seq>` | 读第 seq 块（512B） | 帧：`AA 55 seq(2) len(2) crc16(2) data` |
| `rec close` | 关闭并恢复输出 | `FILE\|CLOSED` |
| `rec wake` | 强制解除静默（异常恢复用） | `FILE\|WAKE` |
| `rec list` | 列文件 | 每行 `文件: recNNN.raw` |
| `rec erase` | 删除全部 | — |
| `rec start/stop` | 开始/停止记录 | `REC 开始/停止: N 字节` |

**静默机制**：`rec open` 后关闭 `dbg_ui/dbg_dump/raw_print` + `esp_log_level_set("*", NONE)`，`rec close` 恢复。
**PC 端必须**：`s.timeout = 0.2`，逐块校验 CRC + 序号，失败重试最多 4 次。

## 6. 今日踩坑清单

| 坑 | 现象 | 解法 |
|---|---|---|
| 串口阻塞读 | 设备静默后脚本永久卡住 | `s.timeout = 0.2` |
| 二进制混入日志 | 回传文件在固定偏移损坏 | `g_quiet` 抑制所有输出 + 分帧校验 |
| 设备静默后无法恢复 | 命令无回显 | `rec wake` |
| 日志等级不生效 | `ESP_LOG_NONE` 仍见输出 | 同时置 `g_quiet` |
| adb 写数据库 | 库损坏、Room 重建空库 | 只能走 App 接口 |
| 磨损均衡 | `esptool read_flash` 拿不到标准 FAT | 需固件侧非 WL 挂载（未做）|
