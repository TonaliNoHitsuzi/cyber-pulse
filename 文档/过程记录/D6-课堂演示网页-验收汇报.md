**串口链路**：板子 USB → 桥（VID:PID 303A:1001 自动枚举，DTR/RTS open 前置 False 防复位，timeout=0.2 防阻塞，静默 8s 自动 `rec wake`，拔插 2s 重扫）→ WebSocket 50ms 增量推流 → 页面 seq×5ms 权威时基画波形。备用通道：Web Serial 页内直连（无 Python 兜底）。

**摄像头链路**（主路线）：手机开发者模式 USB 调试 → scrcpy `--video-source=camera --camera-facing=back --window-borderless --stay-awake` → CYBER-CAM 无框窗口 → 页面默认 gdm 模式 `getDisplayMedia(cursor:"never")` 自动选窗 → `object-fit:cover` 铺满。备选三路内置：MJPEG 局域网流（IP Webcam/DroidCam 预设按钮）、本机/虚拟摄像头（getUserMedia）、手选窗口。

## 3. 手机摄像头调研结论（任务点之二）

1. **小米/HyperOS 无官方「手机当电脑摄像头」通道**（妙享/互联只做投屏传文件；Windows 11 手机连接的相机特性也不支持小米机型）。
2. **事实标准 = 开发者模式(USB 调试) + scrcpy 相机模式**，Android 12+，走 adb shell 的 CameraManager 正规权限路径，**无需 root、无额外授权弹窗**（小米账号/SIM 限制只影响「USB 调试(安全设置)」，不影响本方案）。
3. 开源仓库：
   - **Genymobile/scrcpy**（MIT，★14 万）：主力方案，v2.0+ 相机、v3.x 手电筒/变焦/高帧率
   - **Ruddle/RemoteCam**（MIT，★776）：开源 MJPEG 相机 App，无线备选
   - HunterAP23/ADB_Forwarder（★68）：ADB 转发思路参考
4. 实测小米 15（Android 14）：`--list-cameras` 枚举 5 摄（主摄 4096×3072@30 / 前置 / 超广 / 长焦×2），全程零权限障碍。**无需自写 App**。

## 5. 过程中排掉的关键坑（已沉淀到手册排障表）

| 坑 | 现象 | 解法 |
|---|---|---|
| CYBER-CAM 被最小化 | Chromium 采集列表不含最小化窗口，getDisplayMedia 永久挂起 | 页面加 6s 守护提示 + 手册排障条目 |
| 手机熄屏 | ADB 相机输出黑帧（流活着但纯黑） | scrcpy 加 `--stay-awake` |
| Edge 残留实例吞 flag | 同 profile 二次启动丢失 auto-select 参数 | launch_demo 每次用时间戳新 profile |
| Windows `nul` 保留名文件 | git add 全库卡死（某次误创建） | `\\?\` 长路径删除 |
| cover 露窗口边框 | 铺满裁剪后 scrcpy 标题栏入画 | `--window-borderless`，采集内容实测变纯 1280×960 |

## 7. 讲台部署（三步）

1. U 盘拷整个 `课堂演示/` 文件夹
2. 插板子 USB + 手机 USB（手机提前开好 USB 调试并授权）
3. 双击 `启动演示.bat` —— 体检 → 自动装缺依赖 → 桥 → 相机窗 → 浏览器全自动

所有接口**运行时扫描发现，零硬编码**：串口号（VID:PID）、手机序列号（多台交互选择）、scrcpy/adb/浏览器路径（PATH→本目录 bin→winget→常见位置）。无 Python 的机器：双击 index.html 走 Web Serial 直连。

## 8. 已知限制

- 页面需 Chromium 内核（Edge/Chrome）；`auto-select` 免点击选窗为 Edge/Chrome 特性，其他浏览器需手点一次弹窗
- 手动开浏览器（非一键启动）首次会弹一次屏幕共享选择器，选 CYBER-CAM 即可
- borderless 窗口无关闭按钮，关闭走任务栏
- MJPEG 备选路线需手机与电脑同网；scrcpy 主路线 USB 直连无此要求
