## 五、今天踩的坑

1. **板子一度不枚举**：系统里没有 `VID_303A`，串口只有蓝牙 COM3/4；换数据线、重插后
   COM6 出现。桥每 2 s 重扫，插上自动连，不需要重启。
2. **Chrome `link.disabled` 不靠谱**：致谢页的 `.pageBody{align-items:center}` 串到了
   116 页（整页居中）。实测 `disabled=true` 后规则仍匹配；改成 `media="not all"`，
   只启用当前页 `page.css`。
3. **embeddable Python 隔离模式**：见上，`._pth` 要补脚本目录。
4. **无终端时 `input()` 抛 EOF**：多台手机时 `launch_demo` 会崩；已改为默认第一台。
5. **adb server 常驻**：关掉相机窗口后 `adb.exe` 仍在 5037 端口；彻底清理用
   `adb kill-server`，不影响演示。
