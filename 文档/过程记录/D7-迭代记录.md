# D7 迭代记录（技术明细）

## 1. 固件变更

| 项 | 内容 |
|---|---|
| 控制台 | `CONFIG_ESP_CONSOLE_USB_SERIAL_JTAG=y`，关闭 UART0 主控制台与副控制台 |
| 行尾 | `usb_serial_jtag_vfs_set_tx/rx_line_endings(ESP_LINE_ENDINGS_LF)`（未彻底生效，最终改用十六进制文本）|
| 输出 | `setvbuf(stdout, NULL, _IONBF, 0)` |
| 新命令 | `rec stream <n>`：十六进制文本流式导出 |
| 任务号 | `rec start <task>` → 文件头 12~15 字节 |
| 自停 | 写满 `0x2C0000` 字节自动 stop |
| 限速 | 每帧 `vTaskDelay(1)` |

### 文件格式
```
[16B 头] "CPLS" ver=2 fs start_ms task_id
[每块] ts(uint32) + n(uint16) + n×int16
```

### 流式导出协议（十六进制文本）
```
STREAM|START
<size>
F<seq>,<len>,<hex>
...
STREAM|END
```

## 2. App 变更（v2.5.0）

- 测量页：`闪存 task=<sessionId> [开始记录] [停止记录]`
- 发送 `rec start <sessionId>` / `rec stop`（BLE FFE4，`C:` 前缀）
