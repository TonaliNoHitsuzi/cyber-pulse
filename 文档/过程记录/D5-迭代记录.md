## 2. 串口命令（全部可经 BLE FFE4 `C:` 前缀复用）

```
?                    打印配置
thr/gap/q/dbg/dump/mode/wave/raw/save
led 0-100            灯带亮度
fx 0-7               灯效（1=彩虹生理耦合）
rot a b              静息/最大转速
hue a b              基色/色相跨度
pulse a b            静息/峰值亮度占比
gate r               搏动闸门
decay s              衰减时间常数
cons 0-100           保守度（mfilter=1 时生效）
mfilter 0|1          运动门控开关（默认 0）
motion 0|1           运动判定开关（默认 0）
```

## 3. BLE 协议（当前）

```
FFE1 JSON  {"bpm","bpm2","sc","state","p95","p50","q","beat","t"}
            t = 板载毫秒（单调，统一时钟锚点）
FFE2 波形   100Hz int16 × 10
FFE3 补发   [start_ms int32][n uint16][int16×n]
FFE4 命令   "C:xxx" 文本 / 4 字节 LE 补发起点
```
`ble_msg_t.data` 已扩到 **160 字节**。

## 4. 时钟统一方案（关键修复）

```
板载 esp_timer ms  →  JSON "t"
App 连接时锚定一次 boardToWall = wall_now − t
后续所有数据（实时/补发/UI帧）统一用这个偏移
漂移校正：|err| 在 120ms~5s 时，每次修正 err/8
会话开始记 recordStartWall，丢弃早于它的补发块
```

## 5. 运动判定（已实现，默认关闭）

```
duty = 2 秒滑窗内 dev > thr 的比例（200Hz，400 槽）
静息 7-11% / 走路 34-67% / 跑步 56-89%
拇指按压 13-91%（与走路重叠 → 误判）
→ 默认关闭，仅适合稳定佩戴
```
