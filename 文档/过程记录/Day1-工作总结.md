## 一、项目目标

用 ESP32-C3（板载原生 USB 串口）+ Keyes 压电薄膜压力模块，实现脉搏频率（BPM）检测，

## 四、三案志——伪迹连环破案（本项目最有价值的部分）

三天里三个"幽灵信号"依次告破，每个都有完整证据链：

### 案1：1060ms 幽灵（USB 传输伪迹）
- **现象**：任何测量都输出稳定假 BPM（56.5），信号自相关却指向 714ms
- **破案**：窗口序号遥测证明零丢失，但数据每 1.005s 爆发到达——
  `pyserial` 在 Windows 下 `read(8192, timeout=1)` 攒满 1 秒超时才返回
- **根因**：算法把"读取爆发节律"当成了搏动
- **修复**：timeout=0.05 + 算法时基改用固件序号（seq×5ms）

### 案2：717ms 锁相（值域伪迹）
- **现象**：五轮测量读数冻结 83.9，手表却在 76~82 波动
- **破案**：隔峰匹配率——手表 IBI 732/741ms 时 60/60 全中，769~789ms 时 0~6/60
  → 我们测的是一个独立于生理的稳定振荡源
- **根因**：见案3

### 案3：300~615ms 弛豫振荡（ADC 泵浦，终极根因）
- **判别链**：悬空膜片→幽灵在；胶带固定→幽灵在；**裸引脚浮空→幽灵更强**（p95=273）
- **结论**：幽灵 = ESP32-C3 焊盘 + 连续 DMA 采样的 S/H 电荷泵浦在高阻节点上
  激励出的弛豫振荡。传感器只是改变周期/幅度的旁观者
- **修复（v9.3）**：内部双拉恢复（低阻钳位）+ 采样 10kHz→1kHz（削弱泵浦）
  → 裸引脚实测 p50=2/max=16，完全干净
- **业界印证**：TI 应用笔记 SBAA507（ADC 浮空输入是公认故障态，TI 专门出检测电路）；
  TE《压电薄膜接口手册》（高阻负载的时定数/负载效应问题，及电荷放大器标准方案）

## 五、教训清单（Top 10）

1. **高阻 ADC 节点必须低阻钳位**：浮空/高阻 + 连续采样 = 自激振荡，任何固件算法救不了
2. **上位机时间戳 ≠ 采样时间**：用固件序号做时基，传输抖动即刻免疫
3. **pyserial Windows 大读缓冲 + 长超时 = 周期性断流假象**：小读+短超时
4. **`os.system('cls')` 起子进程会卡住串口读取**：用 ANSI 转义清屏
5. **判真伪的黄金标准是"跟踪性"**：读数跟随生理波动=真，冻结不动=伪迹
6. **空白对照 + 裸引脚 + 折叠平均**是伪迹三件套鉴别法，全部零成本
7. **自适应套自适应是反模式**（用户原则，多次验证）：阈值应锚定上一个事件或固定死区
8. **算法改动必须回归测试**：Day1 曾引入"自适应不应期"造成拒绝级联，靠历史数据回放抓回
9. **双峰（主波+重搏波）信号不能按单峰检测**：隔峰周期法（peak[i+2]-peak[i]）天然免疫
10. **ESP-IDF 工程路径必须纯 ASCII**（ccache 中文路径崩溃）；C3 的 DMA 输出格式是 type2

## 七、硬件升级方案（面包板与器件已购）

背景：TE 手册确认"电压模式 + 负载电阻"的局限（我们现在的形态），
专业方案是低漏缓冲或电荷放大器。按投入从小到大：

### 方案 A：焊接模块空置的 C1 电容（10 分钟，零风险）
- **做法**：C1 位焊 **10nF** 陶瓷电容（信号对地）
- **原理**：给 ADC 采样瞬态提供本地电荷库，进一步压制泵浦；同时滤高频毛刺
- **代价**：压电电荷分压，信号幅度约降为 1/(1+Cp/C1) ≈ 1/3（Cp 约 3~5nF）——
  我们信号余量大（脉搏 100~300 码 vs 噪声底 <40），可承受
- **不推荐 100nF**：衰减约 20 倍，信号余量吃紧
- **预期收益**：配合 v9.3，幽灵残余进一步压低，耦合松一点也能测

### 方案 B：面包板外部分压偏置（30 分钟）
- **做法**：2×100kΩ 分压（3V3-GND，中点≈1.65V）→ 中点接 GPIO0，
  模块 S 也接中点，10nF 滤波（可先不焊 C1，电容放面包板中点对地）
- **原理**：比内部 45k 双拉更标准的电压模式偏置；源阻抗 50k 在 1kHz 采样下稳定
- **变体**：2×1MΩ 可保留更多低频信号（TE 手册：低频端 ∝ 1/RC），但需验证 1kHz 下不自振
- **预期收益**：信号形态更规范，幅度略升

### 方案 C：电荷放大器（进阶/课程加分项，需一颗 CMOS 运放）
- **器件**：TLV9061 / MCP6021 / TLC271 之类低漏 CMOS 运放（同相端接 1.65V 虚地）
- **电路**：运放反相端接压电 S，反馈 Cf=10~47nF 并联 Rf=10MΩ（直流回路），
  输出直接进 GPIO0
- **原理**（TE 手册第 8 节）：零输入阻抗吸收全部电荷，无电压跨越膜片 →
  无时间常数问题、电缆电容免疫、低频响应由 Rf×Cf 决定（10M×47nF → 0.3Hz 下限）
- **收益**：信号质量数量级提升，是仪器级方案；固件无需改动
- **注意**：面包板搭电荷放大器，杂散电容和漏电会引入误差，属"能演示"级

### 方案 D：线缆与屏蔽（随手做）
- 传感器引出线尽量短；S 线与 GND 线双绞；长线时加屏蔽层接 GND（TE 手册 EMI 章节）

**推荐顺序**：A（立刻）→ B（面包板到货后）→ D（顺手）→ C（冲高指标再加）。
A+B 做完后重跑"悬空判别"验证幽灵压制效果，再上真测量。
