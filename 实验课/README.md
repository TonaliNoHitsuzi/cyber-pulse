# 单片机实验课

STM32F103RC 课程实验工程集（来自课程任务包 Product.V2.0，2026-11-07 导入）。

## 目录结构

- `01` ~ `16`：16 个实验工程，每个文件夹内：
  - `App/` 应用层（Main、LED、按键、时钟等业务模块）
  - `HW/` 硬件驱动层（UART、Timer、PWM、ADC 等）
  - `FW/` STM32 标准外设库 V3.5
  - `ARM/` 启动文件 / core_cm3 / SysTick / NVIC
  - `Project/STM32KeilPrj.uvprojx` —— Keil 工程入口
  - `TPSW/` 预留上位机目录（空）
  - `clear.bat` 清理编译产物
- `项目日志.md`：环境搭建与实验推进记录

## 实验清单

| # | 实验 | 内容要点 |

| 01 | F103 基准工程 | 模板工程：LED 闪烁 + 串口每秒打印 |

| 08 | RCC | 时钟配置实验 |
| 09 | 外部中断 | EXTI 按键触发中断 |
| 10 | OLED 显示 | OLED 显示字符串 / 日期时间 |
| 11 | 独立看门狗 | IWDG + KEY1 喂狗 |
| 12 | 读写内部 Flash | 3 按键执行写入 / 读出 / 擦除 |
| 13 | PWM 输出 | 3 按键调节 PWM 占空比 |
| 14 | 输入捕获 | 捕获测量脉宽 / 频率 |
| 15 | DAC | DAC 波形输出 + 串口主机命令协议 |
| 16 | ADC | ADC 采集上传（配合 15 的主机协议 / 上位机） |
| 17 | SNAKE 贪吃蛇 | 综合演示：菜单→游戏状态机，K1 左 / K3 右 / K2 上 / 外接键（PA1）下，左侧竖排比分，吃食加速，K2 长按退回菜单 |

全部工程统一"前后台"架构：SysTick 产生 2ms / 1s 标志，主循环轮询任务。

**综合演示固件（17.综合演示实验）**：16 个课程实验 + 贪吃蛇集成为一个可切换系统，KEY1 左切 / KEY3 右切（环形）/ KEY2 交互（短按 <500ms / 长按 ≥500ms），OLED 顶栏标题+编号，切换即复位（Enter/Exit 钩子），串口 `[NAV]/[KEY2]/[Exx]` 日志 115200，内置上位机协议（10 字节帧：GET_EXP / SET_EXP / TELEM）。游戏进行中 KEY1/KEY3 被征用为方向键，K2 长按回到菜单后恢复导航。

## 板卡资源（从驱动代码反推，无电路图）

| 资源 | 引脚 | 说明 |
|---|---|---|
| LED1 / LED2 | **PC4 / PC5** | 推挽输出 |
| KEY1 / KEY2 / KEY3 | **PC1 / PC2 / PA0** | 上拉输入，按下=低电平；10ms 扫描消抖 |
| OLED（SSD1306 128×64，软件 SPI） | CS=**PB12**，SCK=**PB13**，RES=**PB14**，DIN=**PB15**，DC=**PC3** | 4 线接口 |
| 串口 UART1 | TX=**PA9**，RX=**PA10** | 115200（经 CH340G → COM7） |
| PWM 输出 | **PB5**（TIM3_CH2 重映射） | 实验 13 |
| 输入捕获 | **PA0**（TIM5_CH1，与 KEY3 复用） | 实验 14 |
| ADC 输入 | **PA1**（ADC1 通道 1） | 实验 16 |
| DAC 输出 | **PA4**（DAC 通道 1） | 实验 15/16 |

注意复用：PA0 既是 KEY3 又是捕获口/唤醒脚；PC1/PC2 按键同时充当外部中断线（实验 09）。

## 使用方法

1. 双击实验的 `Project\STM32KeilPrj.uvprojx` 打开工程
2. F7 编译（REBUILD），F8 经 ST-Link 下载
3. 打开串口助手选 COM7、115200 观察输出（工程需勾选 MicroLIB，模板已勾选）

注意：工程使用 AC5 编译器（V5.06），本机为 update 7，兼容可直接编译（01 已实测 0 Error 0 Warning）。
