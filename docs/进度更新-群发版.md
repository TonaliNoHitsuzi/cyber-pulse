## 一、已完成的事

### ✅ 主线：脉搏检测器已验证可用
- **精度**：与华为手表 ECG 同刻对照，误差 **±2 BPM**（跨 2 名受试者、多测量位置）
- **易用性**：拇指按压/胶带/绑带等任意实接触方式可测；佩戴三态自动判定（正确/错位/悬空）
- **输出**：实时 BPM + 信号质量分级 + 佩戴状态 + OLED 屏幕显示（已点亮）

### ✅ 系统：三层质量体系
```
贴膜自检 → 测量中佩戴监视 → 分段质量门控（垃圾段自动剔除）
```
最好成绩：单轮 -0.2 BPM vs 手表。

### ✅ 物理：传感器机制摸透（全有判决实验）
- 信号本质 = 心缩期机械瞬态（压电膜只能感知"变化"，天然免疫静态压力）
- 测量原理 = 事件计时（峰间隔→周期→BPM），对幅度漂移免疫
- 双峰结构 = 生理重搏波（非机械振铃，板加载实验判决）
- 声学免疫：环境声音/说话不干扰（受控声源实验验证）
- **耦合规律**：硬背衬+均压板最优；软垫层（棉花）毁信号；过紧压闭血管
- 产业先例：TE/Emfit 压电膜床垫测心率（文献在工程 references/）
