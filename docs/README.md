## 关键结论速查

| 结论 | 数值 | 出处 |
|---|---|---|
| 测量精度 | ±2 BPM | 同刻手表对照，跨受试者 |
| 最佳单轮 | -0.2 BPM | 胶带轮+分段门控 |
| 系统偏置 | +2~3 BPM（稳定，可标定扣除） | 多轮一致 |
| 位置自由度 | 任意实接触 | 指腹/偏移/手背/大腿/腕部全测过 |
| 双峰本质 | 生理重搏波（非振铃） | 刚性板加载不移频 |
| 声学干扰 | 免疫 | 受控声源全阴性 |
| BLE 射频 | 干净 | 自板广播对照无差 |
| 耦合最优 | 刚性板夹持（p95=154） | 六种方案对照 |
| 耦合禁忌 | 软背衬（棉花 -8.4） | 实证踩坑 |
| 过压现象 | 压闭血管→搏动消失 | 中线≥2600 判定 |
