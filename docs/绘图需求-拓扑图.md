## 2. 形式要求

1. **Mermaid flowchart**，方向 `LR`（或 `TB`，以六个节点+分组美观为准）
2. **节点内嵌图片**：用 HTML 标签形式，例如
   `MCU["<img src='MCU.jpg' style='width:110px'/><br/><b>ESP32-C3 SuperMini</b><br/>主控·1kHz采样+BLE"]`
   （htmlLabels 默认开启即可渲染；图片与本 md 放同一目录）
3. **三个分组用 subgraph 表示**：拇指区(SEN)、手背区(OLED+RING+BTN)、腕部·前臂区(MCU+BAT)，分组标题带"手套部位"说明
4. **配色**：不要在连线/节点里内联 `#hex`（GitHub 渲染差）；如需区分电源/信号线，用 `linkStyle` 少量指定或干脆全部默认+标签文字区分（推荐后者，最稳）
5. **语法安全**（GitHub 渲染五坑）：节点文字含空格/括号/箭头的一律用双引号包裹；不用 Beta 特性；先保证 GitHub 和 https://mermaid.live 都能渲染
6. 图下方配一段**装配铁律**文字（不是图内文字，防拥挤）：
   - 4.5V 只进板子 5V 脚，3.3V 从板子 3V3 引脚出
   - OLED 和传感器只接 3.3V（5V 会烧）
   - 所有 GND 共地；灯环电源直取电池盒并串 1N4148
   - 膜片两侧禁任何软垫层；传感器引线最短并固定在绑带上
   - 上电前万用表核对电池盒极性
