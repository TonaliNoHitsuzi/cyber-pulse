## 一句话项目定义

**用一块压电薄膜 + ESP32-C3，在手套上实现"赛博把脉"——任意贴合位置测心率，±2 BPM 精度，带 OLED 表盘和随心跳律动的灯环。**

## 核心数字（放在最显眼处）

| 指标 | 数值 | 依据 |
|---|---|---|
| 测量精度 | **±2 BPM** | 与华为手表 ECG 同刻对照（跨 2 名受试者、多位置） |
| 最佳单轮 | **-0.2 BPM** | 分段质量门控后 vs 手表 |
| 测量位置自由度 | 任意实接触位置 | 指腹/±0.5cm偏移/手背/大腿/腕部全部实测通过 |
| 佩戴容差 | ≥±0.5cm | 偏移实验统计无差异 |
| 抗干扰 | 声学免疫 | 受控声源实验：正常音量下响应≈0 |
| 续航（预计） | ~20h（不亮灯）/ ~5h（灯环全开） | 3×AAA 碱性电池 |

## 故事线（建议 PPT 章节）

### 第 1 章：我们做了什么
- 从零搭建：环境（ESP-IDF 工具链）→ 固件 → 上位机算法 → 可穿戴集成
- 系统架构图（三层）：采集固件（1kHz DMA）→ 算法引擎（峰普查+隔峰周期）→ 显示/交互（OLED+灯环+BLE）

### 第 2 章：原理（一张图讲清）
- 压电膜只能感知"变化"（AC 耦合）——测不了静态压力，但这恰好完美匹配脉搏（每搏都是一次压力突变）
- 测量本质 = **事件计时**：心缩期冲击→尖峰→峰间隔→心动周期→BPM（对幅度漂移天然免疫）
- 波形特征：每个心动周期两个峰（主波+重搏波），算法用"隔峰间隔"直接量周期

### 第 3 章：验证（最有说服力的部分）
- **同刻对照表**：手表 73 → 我们 75.2（+2.2）；手表 83 → 82.8（-0.2）；手表 75 → 74.1（-0.9）
- 跨受试者验证：第二位同学首次测量一次通过（82.2 BPM）
- 教训彩蛋：顺序测量曾出现 82 vs 68 的"假矛盾"——按压用力本身会升心率，**心率对比必须同刻**

### 第 4 章：把传感器摸透（工程深度担当）
**四个假说判决实验**（每个都是一页PPT的好素材）：
1. 双峰是振铃吗？→ 刚性板加载不移频 → **是生理重搏波**
2. 任意位置能测是全身传导吗？→ 拇指按桌面（单源）幅度不降 → **按压者主导**
3. 环境声音会干扰吗？→ 电脑受控声源七事件全阴性 → **声学免疫**（空气与膜声阻抗差千倍）
4. BLE 射频会干扰吗？→ 自板 20ms 广播对照无差 → **射频干净**

### 第 5 章：质量体系（产品思维）
三层防线：**贴膜自检（三态分类）→ 测量中监视 → 分段门控（垃圾数据自动剔除）**
- 封神战例：一轮数据整轮误差 -9.4 → 门控后 **-0.2**
- 耦合校准器：装配检具（调到信号最大而非最紧——过紧会压闭血管，血压计原理）

### 第 6 章：踩坑史（真实感担当，挑 3 个讲）
1. **幽灵信号三日谈**：假脉搏读数连现三个，逐个破案——USB传输节奏伪迹 → 锁相伪迹 → ADC泵浦振荡（裸引脚自激），最终"低速采样+低阻钳位"根治
2. **中文路径惨案**：工程路径含中文 → caddie 编译器崩溃 → 迁移工程到纯英文路径
3. **读数下坠**：用力不变读数一直掉 → 基线EMA收敛尾巴 → 跳变跟随修复（又一个bug：振荡vs阶跃不分 → 加持续性判据）

### 第 7 章：可穿戴形态 + 展望
- 皮革手套：拇指=传感器区，手背=OLED+16珠灯环+按钮表盘，前臂=主控+电池
- 展望：跑步心率监测（算法频带扩展）、容积传导模型（距离-强度）、BLE 手机端实时曲线

## 展示建议（演讲技巧）

- 开场：现场请一位观众上手测（30秒出数，灯环随心跳闪）——比任何图表都有说服力
