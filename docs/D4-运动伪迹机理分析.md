# 运动伪迹机理分析（D4 夜）

> 结论先行：**单膜、贴皮肤、运动场景下，软件方案已到极限。**
> 差分传感器解决"分离"，模拟前端解决"保真"——两者不能互相替代。

---

## 一、问题的形式化

真实场景里同时叠加了两类问题，性质完全不同：

| | 问题 A：不应期 | 问题 B：步态污染 |
|---|---|---|
| 数学性质 | **非线性限幅器** `y[n]=1 if t−t_last ≥ G` | **线性叠加** `x = pulse + gait` |
| 单独出现 | 可补偿（漏拍检测 + 状态更新 + ×2） | 可补偿（模板匹配/自适应滤波） |
| 本质 | 时间轴量化，**信息被丢弃** | 幅度上遮掩，**信息还在** |

关键在于**顺序**：检波器在补偿环节的下游，被步态推到饱和后输出与输入解耦，再补偿已经没有意义。

## 二、证据链

### 2.1 输出被钳在算法自己的天花板上

| 会话 | 设备输出最大 | i+2 理论上限 |
|---|---|---|
| #1/#2/#3 跑步 | 83 / 85 / 85 | **85.7** |
| #4/#5 走路 | 84 / 85 | **85.7** |

五组数据、三个不同的人，最大值全部停在 85，从未突破。`60000/(2×350ms)=85.71`。

### 2.2 峰间隔精确卡在不应期

在录到的波形上复刻固件算法：

| 会话 | 峰数 | 间隔中位数 | 落在 300-400ms |
|---|---|---|---|
| #2 跑步 | 176 | **350ms** | 73% |
| #5 走路 | 169 | **350ms** | 65% |

间隔分布是尖峰而非生理的钟形 → 检测器被不应期"限速"。

### 2.3 波形主频 = 步频/2，与动作无关

| 会话 | 动作 | 步频 | 步频/2 | 频谱主峰 | 自相关 |
|---|---|---|---|---|---|
| #1 | 跑步 | 173 | 86 | 88 | 83 |
| #2 | 跑步 | 162 | 81 | 81 | 79 |
| #3 | 跑步 | 178 | 89 | 103 | 91 |
| #4 | 走路 | 111 | 56 | 55 | 56 |
| #5 | 走路 | 118 | 59 | 59 | 58 |

七组数据（含前一日两组）全部落在步频/2 上，误差 ±3%。

### 2.4 平移不激励压电膜（决定性实验）

卡片法：压电膜贴卡片背面、手机同卡，摆动 1-3.6 Hz，峰值加速度 2.9g。

| 指标 | 结果 |
|---|---|
| 波形时间轴 | 完美（1000ms/块，零间隙） |
| 波形↔6 轴 IMU 相干性 | **0.000~0.003** |
| 包络互相关（±5s） | 最佳 r = **-0.07** |

**结论：压电膜是应变传感器，对刚体平移几乎不响应。** 步态伪迹来自**皮肤/握持引起的膜弯曲**，与加速度无关。

推论：**用 IMU 做 ANC 参考在物理上就不成立**（此前实测相干仅 0.17，正是这个原因）。

## 三、已排除的方案

| 方案 | 排除理由 |
|---|---|
| 调阈值/不应期/CV 门 | 只改变饱和点，输出仍与真实心率解耦；实测"改参数→改结果"（78→67→58→52） |
| Kalman 突变点检测 | 假设观测是状态的带噪版本；饱和时二者无函数关系 |
| 频率 ×2 恢复 | 仅适用于**漏拍**（间隔=2T）；饱和时间隔=G，1/G 不是 T 的整数倍 |
| 模板匹配 | 需要可辨识的形态；运动中波形被步态淹没 |
| IMU 自适应抵消（ANC） | 加速度不是该传感器的输入变量（相干 0.003） |
| 机械隔离 | 皮肤是柔性介质，步态必然经皮肤传导，无法隔离 |
| 高频带分离（3-12Hz） | 脚步是冲击，频谱宽带；3-12Hz 峰仍拟合步频/2（86/80/90） |

## 四、RC 理论（解释波形为何"尖"）

等效电路：电荷源 ∥ 膜电容 Cp，经漏电阻 R 输出。

$$H(s)=\frac{s\tau}{1+s\tau},\quad \tau=RC_p,\quad f_c=\frac{1}{2\pi RC_p}$$

$$|H(j\omega)|=\frac{\omega\tau}{\sqrt{1+(\omega\tau)^2}},\qquad \angle H=90^\circ-\arctan(\omega\tau)$$

阶跃响应：$V(t)=\frac{Q_0}{C_p}e^{-t/\tau}$

| R | τ | f_c | 1Hz 衰减 |
|---|---|---|---|
| 10 MΩ | 11 ms | 14.5 Hz | -23 dB |
| 100 MΩ | 110 ms | 1.45 Hz | -4.9 dB |
| 1 GΩ | 1.1 s | 0.145 Hz | -0.1 dB |

ADC 采样负载：$R_{eff}\approx 1/(C_s f_s)=1/(2\text{pF}\times1\text{kHz})=500\text{ M}\Omega$ → f_c ≈ 0.29 Hz。

**f ≪ f_c 时传感器是微分器**，把基频压下去、谐波留下 → 波形呈尖脉冲，频谱上 2/3 次谐波反而更强（实测比 0.22-0.58）。数值积分验证：积分后谐波比降到 0.07-0.25。

**数字逆滤波** $H^{-1}(s)=1+1/(s\tau)$ 可恢复波形形状（利于双峰识别），但**改变不了主频**——LTI 环节不产生也不消灭频率。

## 五、剩下的路

### 路线 1：差分传感（解决"分离"）

两片膜相距 3-5 cm，一片压动脉、一片压在无动脉处：
- 步态应变是**共模**（两片都感受到）
- 脉搏是**差模**（只有动脉那片有）
- 相减直接消掉步态，**不需要任何先验知识**（不用步频、不用 IMU）

硬件成本：多一片膜 + 一路差分放大。

### 路线 2：模拟前端（解决"保真"）

目标不是分离，而是**不丢信息**：
- 1 GΩ 偏置 + CMOS 运放跟随器 → f_c < 0.3 Hz
- 或电荷放大器：输出 = −Q/C_f，天然无低通
- 好处：波形变成正常脉搏波（清晰收缩峰 + 重搏波），峰检测/模板匹配才有用武之地

**注意：前端滤波不能分离脉搏和步态**——两者都在 1-3 Hz，任何线性滤波器都会同时作用。

### 路线 3：空间选择性（折中）

局部刚性压板 + 小孔：压板承担周围皮肤形变，只有孔下（动脉上方）一小块皮肤能压到膜上。
不是"隔离"（膜仍贴皮肤），而是**分流传导路径**。

## 六、对周六汇报的影响

**可以讲的**（有数据、有理论、有实验）：
1. 静息测量精度 ±1 BPM（已验证）
2. 定位出运动失效的完整机理链：应变本质 → 步态共模 → 不应期饱和 → 输出=30/G
3. 量化的算法天花板（85.7 BPM）、实测饱和证据
4. 用加速度做参考的 ANC 为何无效（相干 0.003 的决定性实验）
5. 五条已排除方案及排除理由

**不要讲的**：运动场景的心率数值（没有任何一组可信）。

**诚实的结论**：这是个**传感器物理层面的限制**，不是算法不够聪明。改进方向明确（差分/前端），但需要新硬件。
