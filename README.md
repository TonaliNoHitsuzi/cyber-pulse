# 赛博把脉 · Cyber Pulse

ESP32-C3 + 压电薄膜的**可穿戴脉搏检测系统**（单片机课程设计 · 第 22 组）。

把压电薄膜贴在手腕上，采集心跳引起的体表微振动（BCG），在板端做检峰与心率解算，
通过 BLE 推给手机 App；课程汇报用一套 117 页的网页讲稿，现场用本机演示平台
同屏展示实时波形、BPM 与手机后摄。

- 课程：大三上 · 单片机课程设计
- 汇报：2026-11-08（已完成）
- 讲稿：117 页（`汇报讲稿/`，纯静态网页）
- 许可：[MIT](LICENSE)

> **数据与隐私**：原始采集数据（1 kHz 波形、数据库、导出文件）、现场人物照片和
> 群聊记录**不在本仓库**。确有需要请开 Issue 说明用途，维护者视情况提供。

## 成果一览

| 指标 | 结果 |
|---|---|
| 静息心率 MAE（4 人） | **5.2 bpm**（77/77、75/80、82/79、89/76） |
| 跑后设备读数 | 78–81 bpm（手表 112–152）→ 跑步模式**不可用** |
| 检峰硬上限 | **85.7 bpm** = 60/(2×0.35) |
| 采样率 | 100 Hz 与 1 kHz 的 RMSE ≤4.3 bpm（离线重采样） |
| 降速时间常数 τ | 42 / 45 / 65 / 65 s |
| 相关性（n=4，B 级） | BMI↔跑后 ρ=1.00；BMI↔τ ρ=0.95；运动量↔心率 ρ≤0.40 |

**边界写清楚**：跑步时设备读到的是步伐不是心跳（峰重叠 + 步频耦合，见
`文档/过程记录/Day5-工作总结.md`）；硬件升级（差分对、电荷放大器）只做到方案与
讲解页，没有改板；样本仅 4 人，相关性只能当现象描述。

## 快速开始

### 1. 网页讲稿（最轻）

需要 Node.js（18+）：

```bash
node 汇报讲稿/serve.js 8088
# 打开 http://127.0.0.1:8088/
```

键盘：`→/空格/单击/滚轮` 翻页，`G` 总览，`N` 备注，`F` 全屏，`P` 打印。
在线快照（临时托管，可能失效）：<https://unn6vtiejhyvk.ok.kimi.link/#1>

### 2. 现场演示平台

需要 Python 3.10+，并安装 `pyserial`、`websockets`：

```bash
python 课堂演示/serial_bridge.py
# 网页 http://127.0.0.1:8100/?cam=gdm （WS 8765）
```

- 板子以 USB-Serial-JTAG 接入（VID:PID `303A:1001`），桥自动枚举；
- 手机相机：开启开发者选项 + USB 调试，用 [scrcpy](https://github.com/Genymobile/scrcpy)
  以相机源启动（`--video-source=camera --camera-facing=back`），网页选「窗口采集」；
- 一键脚本：`python 课堂演示/launch_demo.py`（详见 `课堂演示/演示手册.md`）。

### 3. 固件

ESP-IDF **5.4.1**：

```bash
cd 固件
idf.py set-target esp32c3
idf.py build flash monitor
```

接线：ADC=GPIO0，SDA=GPIO8，SCL=GPIO10，按键=GPIO4，灯带=GPIO5；OLED 只接 3V3，
电池经 5V 输入。

### 4. App

`App/` 为 Gradle 工程，可直接用 Android Studio 打开；`App/赛博把脉-v2.5.0-debug.apk`
是可直接安装的调试包。

### 5. 实验课

`实验课/` 是另一门课的 STM32F103 实验工程（Keil），与主线项目无关，按原样归档；
仓库只保留源码与工程文件，编译产物已排除。

## 系统要点

- **传感器**：PVDF 压电薄膜，电荷源 + 约 1.1 nF；RC 高通 τ≈0.55 s，静态压力测不了，
  只响应动态搏动。
- **采样**：1 kHz，5 样本窗口取 min/max → 200 行/s；10 kHz 会自激。
- **检峰**：350 ms 不应期 + 隔峰 i+2 + 中值；七种质量状态，只有 GOOD 出数。
- **时间基准**：固件采样序号 ×5 ms，免疫主循环卡顿。
- **存储**：4 MB 闪存按 1 kHz 存全档，约 26 分钟；导出走十六进制文本通道。
- **演示**：BLE 100 Hz 波形流 + 历史补发（按序号去重）。
