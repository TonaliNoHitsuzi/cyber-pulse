# 汇报讲稿 · 技术与视觉规格 v1

> 目标：一个**组装式**的网页讲稿。文字、图片、数据都是素材，通过 `content/*.js` 引用组装；版式与引擎不动。
> 主题：**冷白科技**（浅色，投影友好），蓝 + 橙双色体系。

---

## 1. 画布

| 项 | 值 |
|---|---|
| 逻辑画布 | **1600 × 900**（16:9） |
| 缩放 | `transform: scale(min(vw/1600, vh/900))`，居中 |
| 安全边距 | 左右 96px，上下 72px |
| 打印 | 每页 1600×900，`page-break-after` |

为什么固定逻辑画布：投影分辨率千差万别，只有固定画布 + 等比缩放才能保证任何机器上版式一致。

## 2. 设计令牌

```css
/* 底色 */
--bg:      #fbfcfe;   /* 近白，纯白投屏刺眼 */
--panel:   #ffffff;
--line:    #e2e8f0;
--grid:    #eef2f7;

/* 文字 */
--txt:     #0f172a;   /* 对比度 ≈ 15:1 */
--dim:     #64748b;
--faint:   #94a3b8;

/* 主色（五色，各有语义，不可混用） */
--blue:    #1d4ed8;   /* 结构 / 标题强调 / 硬件线 */
--orange:  #ea580c;   /* 警示 / 关键数字 / 算法线 */
--teal:    #0f766e;   /* 正确 / 通过 / 实验线 */
--red:     #b91c1c;   /* 失败 / 伪迹 / 边界 */
--violet:  #6d28d9;   /* 组织线 */
```

**语义固定**：蓝=硬件、橙=算法、青=实验、紫=组织、红=错误。这样观众不看文字也知道这条线在讲什么。

## 4. 组件清单（十四种）

### 4.1 结构类

| 组件 | 说明 |
|---|---|
| `page` | 一页：`header`（坐标徽章）+ `body` + `footer`（灰字注释） |
| `grid2` / `grid3` | 两栏 / 三栏 |
| `split` | 左文右图（或反之），固定 5:5 / 4:6 |

### 4.2 内容类

| 组件 | 用途 | 字段 |
|---|---|---|
| `h` | 标题（h1/h2/h3） | `level`, `text` |
| `p` | 正文 | `text`（支持 `**粗**`、`` `代码` ``） |
| `ul` | 列表（可逐条） | `items`, `frag` |
| `quote` | 收束句（大字、左侧色条） | `text`, `color` |
| `stat` | 数据卡组 | `items: [{k, v, unit, color}]` |
| `table` | 表格 | `head`, `rows`, `highlight` |
| `figure` | 图片 + 图注 | `src`, `caption` |
| `chart` | ECharts 容器 | `data`, `type`, `height` |
| `badge` | 新增硬件/功能三行卡 | `what`, `why`, `demo` |
| `annot` | 页脚灰字（时间归属说明） | `text` |
| `steps` | 横向编号流程 | `items`, `frag` |
| `compare` | 前后/方案对比两列 | `left: {title, items}`, `right: {...}` |
| `formula` | 公式（HTML/CSS 排版，不用 MathJax） | `html`, `caption` |
| `dag` | 依赖图（节点 + 带类型的边） | `nodes`, `edges`, `focus` |

### 4.3 逐条出现（fragment）

任何组件可加 `frag: true`，页面内按 ≤ / 空格 逐条点亮；全部点亮后再翻页。

## 6. 动画

| 类型 | 参数 |
|---|---|
| 页面转场 | 280ms，淡入 + 位移 1.2% |
| 条目点亮 | 140ms，位移 8px → 0 |
| DAG 连线生长 | 420ms，stroke-dashoffset |
| 数字滚动 | 500ms，ease-out |
| **原则** | 同一时刻只有一个动画在跑；不做循环动画（除波形） |

## 7. 组装式架构（一页一文件夹）

```
汇报讲稿/
├── index.html            外壳
├── deck.js               ★ 总程序：加载 / 渲染 / 导航 / 总览 / 备注
├── style.css             ★ 全局风格：令牌 + 十四种组件
├── content/
│   └── manifest.js       组装顺序（只放 slug 数组）
├── pages/                ★ 每页一个文件夹，自包含
│   └── d1-01-hardware/
│       ├── page.js       页面对象（id/day/line/title/notes/css）
│       ├── content.json  文案（blocks）
│       ├── page.css      页级微调（可选）
│       └── assets/       本页图片（可选的本地素材）
├── renderers/            DAG / 转场等专用渲染器
├── lib/                  echarts / gsap（本地）
└── tools/                版式预检等
```

**页面对象契约**

```js
export default {
  id: 'd1-01',            // 全局唯一，供 [[d1-01|文字]] 跳转
  day: 1, line: 'hw', no: '01',
  title: '我们手上的东西',
  notes: '讲者备注',
  css: 'page.css',        // 可选，页级样式
  bare: false,            // true = 不显示页头
  center: false,          // true = 页体垂直居中
};
```

**组装流程**：`deck.js` 读 `manifest.order` → 动态 `import(page.js)` → `fetch(content.json)` → 注入 `page.css` → 合并成 `{...meta, blocks}` → 渲染。

**页内跳转**：文案里写 `[[d1-01|见硬件条件]]`，渲染成链接，点击调用 `gotoPage(id)`。

### 内容块规范

```js
{
  id: 'd1-04',
  day: 'D1',
  line: 'algo',              // hw | algo | exp | org
  title: '第一次幽灵：测到的不是心跳',
  notes: '讲者备注，不上屏',
  edges: { deps: ['d1-03'], leads: ['d4-02'] },   // 供 DAG 用
  blocks: [ /* 十四种组件之一 */ ]
}
```

**改文案只动 `content/`，换图只改 `src`，调顺序只动 `manifest.js`。**

## 11. 转场设计（矩阵聚焦）

### 11.1 时间轴

```
0ms      全局矩阵（日 × 线，点的大小 = 事件数，目标点脉冲）
500ms    镜头推进（viewBox 插值，900ms，easeInOut）
1400ms   矩阵淡出，局部依赖图淡入，坐标标签出现
2000ms   可继续翻页进入内容
```

### 11.2 镜头推进的实现

不是缩放 div，而是**移动 SVG 的 viewBox**：

```
from: 0 0 W H
to:   (目标点 ± 1.6 个格子)
```

这样每一步的"放大倍率"是连续的，且文字会随焦距自然放大，不会模糊。

### 11.3 矩阵的表格感

- 完整表格线（行列分隔）
- 当前行 + 当前列整条底色加深（`#f1f5f9`），暗示"现在讲这里"
- 表头写 **Day 1 … Day 7**（不用 D1 这种黑话）
- 节点尺寸只做轻微区分（半径 5~10），大小=事件数的暗示，不喧宾夺主
- 目标节点：实心 + 外光晕 + 脉冲环

### 11.4 聚焦后只保留三类关系

| 角色 | 位置 | 说明 |
|---|---|---|
| 前一天 · 同一条线 | 左 | 上游（带箭头指入） |
| 后一天 · 同一条线 | 右 | 下游（带箭头指出） |
| 同一天 · 上一条线 | 上 | 关联（虚线） |
| 同一天 · 下一条线 | 下 | 关联（虚线） |
| 当前 | 中 | 高亮 + 光晕 |

### 11.4 坐标信息转化为标签

矩阵阶段：靠行列位置表达"第几天 × 哪条线"。
聚焦后：位置信息消失，改为顶部胶囊标签 `● D5 · 算法`。
进入内容页：标签变为页头的坐标徽章 `D5 · 算法 · 事件 08`。

**三次表达，一次比一次小**：位置 → 胶囊 → 徽章。

### 11.5 分步推进

- 第 1 次按 →：镜头推进（900ms），停在邻域图
- 第 2 次按 →：进入内容页
- 等待时右下角显示"按 → 继续"

### 11.6 可交互

聚焦后的局部图可点击节点跳转（Q&A 用）。
矩阵页可点击任意格直接跳转。

## 12. 线性化编排（二维 DAG → 一维演讲）

### 12.1 主轴与标签

```
主轴：Day 1 → Day 6（时间不可逆，观众的时间感来自事情发生的顺序）
线：只做标签，不做分区——标签 + 图标 + 主题色
页内排序：按事件的因果顺序，不按线分组
```

一天之内的事情是互相触发的（看到信号奇怪 → 改算法 → 发现是硬件），按线分组会打断因果。

### 12.2 五条线的视觉编码

| 线 | 颜色 | 图标 |
|---|---|---|
| 硬件 | `#1d4ed8` 蓝 | 芯片 |
| 算法 | `#ea580c` 橙 | 波形 |
| 实验 | `#0f766e` 青 | 烧瓶 |
| 组织 | `#6d28d9` 紫 | 人 |
| 演示 | `#0ea5e9` 天蓝 | 屏幕 |

图标为内联 SVG，随坐标徽章出现：`[图标] Day 5 · 算法 · 事件 08`。

### 12.3 时间轴进度

右下角显示**本节（当天）剩余页数**（进度条 + 「还剩 N 页 / 本节末页」），按 day 分段计算；封面/目录/转场页不显示。

跨页定位走右上角总览：按天×线分组列出页面，点击某页先播放目录矩阵的镜头推进动画（定位到该格），再跳转，方便现场临时改顺序。

### 12.4 跨天呼应（**不命名**）

跨天的因果关系用 **toast** 承载，**禁止出现"伏笔/铺垫/应验"等字样**。

**形式**：一句话，通常是问句或断言，像"预言"而不像"标注"。

```
        ┌──────────────────────────────────┐
        │ ?  这个 350 毫秒，以后会变成一条硬上限。 │
        └──────────────────────────────────┘
```

**规范**：

| 项 | 规定 |
|---|---|
| 组件名 | `echo`（内部名，不上屏） |
| 位置 | **水平居中**，落在画面中部（`50% / 50%`） |
| 动效 | **从画面上方飞入**（起始 `-140%`），带轻微回弹，停在中间 |
| 触发 | **不是进页即出**，而是本页所有内容讲完后的**最后一步**（作为最后一个 fragment） |
| 视觉 | 虚线边框 + 琥珀底（埋）／实线 + 青底（收）；图标只用 `?` / `!` |
| 文案 | 一句，≤ 30 字，必须是问句或预言口气 |
| 停留 | 停在中间不消失，直到翻页 |

| 类型 | 内部值 | 视觉 | 文案示例 |
|---|---|---|---|
| 埋 | `kind:'ask'` | 虚线琥珀 | 「这个数字以后还会出现一次。」 |
| 收 | `kind:'ans'` | 实线青 | 「它回来了，而且比上次更硬。」 |

**为什么放在最后**：它是一句总结性的预言，必须等这一页的事实都讲完，才有"回头一想"的力量。提前出现就变成了装饰。

**为什么放中间**：它不是页面的附属信息，而是这一页的落点。飞入 + 停留，让观众的眼睛跟着它走。

### 12.5 同学的两段（外部插叙）

按内容性质插入，不单独成章：
- 压力传感器横向对比 → 紧跟 Day 1 硬件页之后（解释"为什么选压电"）
- 实验设计 → Day 5 范式转向之后（解释"我们怎么验证"）

外部页统一用资料卡容器（左侧橙色条 + 图注标"外部素材"），视觉上明确是别人的东西。
